# CLAUDE.md

SGCRC (Sistema de Gestión de Cobros Recurrentes): recordatorios de cobro recurrentes por correo. Backend Node.js con `http` nativo + SQLite; frontend React 18 + Vite.

Este archivo es el punto de entrada. El detalle vive en:

| Documento | Cuándo leerlo |
|---|---|
| `AGENTS.md` | Convenciones del repo, comandos, arquitectura y gotchas. **Empezar aquí.** |
| `backend/CLAUDE.md` | API, scheduler, SMTP, migraciones, multi-tenant. |
| `sgcrc-frontend-export/CLAUDE.md` | Vistas, componentes base, estilos y theming. |
| `docs/despliegue-docker.md` | Despliegue, actualización, backups y diagnóstico en la VPS. |

`docs/superpowers/` guarda planes y diseños fechados: son registro histórico, no referencia. Si contradicen el código, manda el código.
